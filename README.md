## ✨ Features & Architecture

### 🎨 User Experience & Design
- **Modern UI/UX Design:** Clean typography, glassmorphism navigation, and responsive card layouts
- **Dark & Light Mode:** Seamless theme switching with persistent local storage preferences
- **Smooth Animations:** Intersection Observer scroll reveals, fade-ins, and responsive hover transitions
- **Mobile Navigation:** Responsive hamburger drawer with touch-friendly navigation

### 🔍 Search Engine & Identity Optimization (SEO)
- **Canonical URL:** Fully resolved to `https://mahbub-40.vercel.app/`
- **Schema.org JSON-LD:** Implemented `Person`, `WebSite`, and `WebPage` structured data with explicit `sameAs` entity links
- **Social Graph Metadata:** Open Graph (OG) and Twitter Card tags configured for rich link previews
- **Crawlability:** `robots.txt` and XML `sitemap.xml` configured for Googlebot and search indexers
- **Semantic HTML5:** Strict single `H1` hierarchy, semantic landmark tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), and accessible ARIA attributes
- **Image Accessibility:** Descriptive `alt` tags and `loading="lazy"` attributes across all media assets
